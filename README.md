# CoreStream · Kharon prototype

A clickable prototype of Kharon, an agent that traces sanctions Exposure in an analyst's graph. Kharon is scripted (no live model) and the case is fictional.

**Live:** https://robdhyman.github.io/corestream-prototype/

```bash
npm install
npm run dev   # http://localhost:5173, best at 1520×1088
npm test      # the state layer's tests (vitest)
```

`?scene=S4` opens a scene; `[` and `]` step through them; `Shift+R` restarts.
